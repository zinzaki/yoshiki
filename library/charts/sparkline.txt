# Sparkline — a trend in one line, kept light. Braille dots or low blocks —
# never the full block █ (it reads as a heavy slab).

## families — pick by how much resolution the line has earned
 braille line   ⡠⠔⠒⠊⠉⠉⠑⠢⠤⠄⠂⠁⠂⠄⠢     finest, airy (2×4 dots per cell)
 braille fill   ⣀⣄⣆⣇⣧⣶⣷⣿⣿⣷⣧⣇⣆⣄⣀     a filled area, still not a slab
 low blocks     ▁▂▃▄▅▆▇▆▅▄▃▂▁▂▄▆       eight steps, universally installed
 dots           ․˳•˚°˚•˳․˳•˚°˚•˳       a whisper — for a line that is context
 bars           ⡇⡆⡄⡀⡄⡆⡇⣇⣧⣶⣷⣿         column-per-sample, when count is small

## anchored — a line without a scale is decoration

## marked — one sample matters more than the run
 p99    ▁▂▄▃▅▆▇▆▄▃             a plain run
