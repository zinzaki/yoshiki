# Physics — how the world behaves

The rules that make every object feel like it belongs to the same place. Graphic zone unless noted.

| file | governs |
|---|---|
| `elevation.md` | the surface ladder `bg.app → surface → raised → hover`; depth by tone and glass, a shadow only for layers floating above a scrim |
| `light.md` | where light comes from, how the glow sits behind content, specular edges on glass |
| `motion.md` | durations, easing curves, enter / exit choreography, one orchestrated moment per page, the reduced-motion replacement for every animation |
| `density.md` | comfortable and compact; row heights for web and for Slint desktop apps |
| `radius.md` | 6 · 10 · 14 · pill — which object takes which |
| `space.md` | the spacing scale and rhythm |
| `layout.md` | grids, breakpoints, content widths for web; window and pane sizes for desktop |

Text-zone rhythm (monospace grid, alignment, spacing in characters) stays in
`canon/objects/text/space.md`.
