Code and terminal

Where the eye spends hours

Syntax roles and the ANSI set come from the same source as the interface. The terminal keeps its own ground in every palette — it is an island, not a page.

mount.tspalette.ymlroles.md
// the palette is mounted, the roles answer
export function mount(palette: Palette) {
  const surface = palette.role('bg.surface');
  const edge    = palette.role('accent.edge');
  if (contrast(surface, palette.role('text.primary')) < 4.5) {
    throw new Error('a floor is a floor');
  }
  return { surface, edge, density: 1.0 };
}
