canon lexicon

The form, apart from colour.

Half of this language survives in a plain terminal, a diff, a commit message or a chat window where colour cannot go. Structure carries it: one glyph per meaning, frames that say soft or hard, tracking that turns a word into a mark, and motion drawn with squares and dots instead of a slab. Click any glyph to copy it.

01 glyphs

See, don't read.

One glyph carries one meaning and keeps it everywhere — terminal, chat, comments, docs. The eye decodes a shape faster than a word, and a shape survives colour-blindness, greyscale and a monochrome print. Restraint is the law: one or two glyphs per line, never a parade.

Box-drawing and braille are the safest of all: terminals draw them programmatically, so they align whatever the font.

02 frames & space

A soft capsule, or a hard spine.

Rounded corners for the calm register, double rules for the technical one — and one sharp mark permitted inside a soft frame, never two. Content never touches the wall: the margin is composition, not leftover.

Tracking turns a word into an emblem. Body text is never spaced; only marks are.

03 motion

Density as meaning.

A spinner lives at ~90ms — a breathing tempo, not a dizzy whirl. Smoothness belongs to progress, and progress is drawn with sub-symbols: braille cells that fill, or a ▰▱ tape. Never a solid slab bar, and never a shimmer.

Everything here holds one honest frame under prefers-reduced-motion rather than vanishing.

04 charts in text

Numbers, drawn with squares and dots.

One role colour per run, and the first series is gold — the subject. A threshold is a mark, not a filled band. A chart that needs a fourth hue needs small multiples instead.

05 messaging & comments

Where colour cannot go.

Chat clients, bot messages, commit bodies and code comments strip every hue you had. What is left is the frame, the glyph and the column — and the language was built so that what is left is still the language.

// ╭─ resolve ───
// │  a role → the token it points at, per theme
// ╰╴
//
// ◆ washi remaps text.gold: the edge gold fails as a word on paper
// ⚠ never take a raw token here — it carries no contrast promise
fn resolve(role: &str, theme: Theme) -> Token {
    theme.roles.get(role).unwrap_or(Token::Bone)
}
