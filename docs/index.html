The workshop

Where the pieces come from

References are taken apart component by component, each part is named and traced, and only what survives eleven filters is rebuilt. Nothing is copied: every piece is written again from its notes, in yoshiki's own roles.

265REFERENCES

Photographs and screens the owner collected, taken apart one by one.

782COMPONENTS FOUND

Every distinguishable part named, described and traced back to its source.

11FILTERS

Substance, zone, register, distinctness, palette proof, scale, accessibility, craft.

246REBUILT

Each one written again as a self-contained piece that works in every palette.

Use it

One source, every surface

The same tokens drive the web kit, Slint desktop apps, terminal themes, Figma variables and Tailwind. Pull a single piece or the whole palette.

WEB · CSS ROLES 
/* one line; every role follows the palette */
@import "yoshiki-design/css";

.card { background: var(--r-bg-surface); color: var(--r-text-primary); }
.card--active { border: 1.5px solid var(--r-accent-edge); }
DESKTOP · SLINT 
// desktop, same tokens
import { Yoshiki } from "yoshiki.slint";

Rectangle { background: Yoshiki.bg-app;
  Text { color: Yoshiki.text-primary; } }
ONE PIECE 
# pull one piece into your project
npx shadcn add zinzaki/yoshiki/glass-menu

# or take the whole palette
curl -O canon/palettes/night-beige/night-beige.css
