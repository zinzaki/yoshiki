a warm design language

Lacquer, bone and gold — struck rarely by a single spider-lily scarlet. Install one token file, palette.css, and the roles contract arrives with it: every value already proven against every surface it can land on.

◆

Colour earns its power by being rare.

01 the one law

Colour earns its power by being rare.

A signal used everywhere is dead. So a screen is almost all quiet tone, and the rare strike lands like a seal — chosen by meaning, never by taste. The budget below is not a preference. It is the mechanism.

02 the gold law

Gold is the seam, never the slab.

Nobody would wear a solid-gold watch, but a gilded edge is precious. So gold lives only as a line, an edge, a frame or a glyph — the largest gold surface the language allows is a two-pixel stroke. A primary action is a gold-framed tone surface with gold text, and the difference stops being subtle the moment you see the two together.

Scarlet is the exception that proves it: scarlet may fill, because a fill is itself the rare event. One per screen, on the thing you cannot undo.

03 the palette

Every shade has a job — and a proof.

Raw tokens are the paint. Roles are the contract: reach for text.body or action.edge and the right value arrives in either theme, at a contrast measured against every surface it can land on. The build fails if one cell drops below its floor.

04 one source

Thirteen targets, generated.

Nothing downstream is maintained by hand. One palette file is the source; the build bakes every theme, every token export, this site's colours, the banner and the mark, then CI re-runs it and fails on any drift. A palette that can rot is not a design system.

05 point an agent at it

A repository that steers the model.

Give an agent the link and nothing else. It reads AGENTS.md, learns the read order and the laws, then loads only the module its task needs — palette, CLI, components, comments, chat, image prompts. There is a machine index at llms.txt and W3C design tokens for tooling that wants structure instead of prose.
