the three laws this file will not let you break
gold gilds
there is no gold-filled button in the kit — a primary action is a tone surface with a gold edge
depth steps
surfaces climb bg.app → surface → raised → hover; only a dialog casts a shadow
never colour alone
every status class expects a glyph beside it
only padding moves — type, edge and radius never do
